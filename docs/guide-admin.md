# คู่มือการใช้งาน AsakanLeadFlow — สำหรับ Admin / Team Lead

---

## 1. โครงสร้างระบบ

```
Pipeline (โปรเจกต์)
  └── Stages (ขั้นตอน Funnel)
        └── Leads (ลีดใน Stage)
              └── Activities (Note, Stage change, Recall)
              └── Reminders

Facebook Page / LINE OA
  └── Distribution Rule → Pipeline + Team/User
        └── Method: Round-Robin หรือ Random

Auto Recall Rule
  └── Stage + ไม่มีกิจกรรม X วัน → คืนส่วนกลาง
```

---

## 2. การตั้ค่า Pipeline

### สร้าง Pipeline ใหม่

1. ไปที่ menu **Pipelines**
2. กด **+ New Pipeline**
3. กรอกชื่อ, สี, คำอธิบาย
4. กด **Save**

### จัดการ Stage ของ Pipeline

1. คลิก **⚙ จัดการ** ที่ Pipeline
2. เลือก tab **ขั้นตอน Funnel**
3. เพิ่ม Stage โดยกดการ์ด **+**
4. กรอกชื่อ Stage และสี
5. ใช้ **◀ ▶** เพื่อเรียงลำดับ
6. Stage สุดท้ายควร tick **เลิกติดตาม** เพื่อย้ายลีดออก Funnel

**Template สำเร็จรูป:**
- **อสังหาฯ**: ลีดใหม่ → โทรติดต่อ → กำลังติดตาม → ส่งคูปอง → นัดเข้าชม → เข้าชมแล้ว → ปิดจอง → ทำสัญญา
- **Sales**: ลีดใหม่ → ติดต่อแล้ว → นำเสนอ → ปิดการขาย
- **Service/Course**: สนใจ → ส่งข้อมูล → ทดลองใช้ → สมัคร/ซื้อแล้ว

---

## 3. Distribution Rule — กฎกระจายลีด

กำหนดว่าลีดที่เข้ามาจาก Facebook Page ใด จะไปยัง Pipeline ใด และมอบหมายให้ใครรับ

### ตั้งค่า

1. ไปที่ menu **กฎกระจาย**
2. กด **+ เพิ่มกฎ**
3. เลือก:
   - **Page**: Facebook Page ที่รับลีด
   - **Pipeline**: Pipeline ปลายทาง
   - **ทีม หรือ ผู้ใช้**: ใครรับลีด
   - **วิธี**: Round-Robin (เวียนตามลำดับ) หรือ Random (สุ่ม)
4. กด **Save**

> ลีดใหม่จะถูก assign ให้สมาชิกในทีมโดยอัตโนมัติตาม method ที่เลือก

---

## 4. Auto Recall Rule — กฎเรียกคืนลีด

ลีดที่ไม่มีกิจกรรมเกิน X วัน จะถูกคืนกลับส่วนกลาง (assigned_to = null) เพื่อให้คนอื่นรับได้

### ตั้งค่า

1. ไปที่ Pipeline → **⚙ จัดการ** → tab **กฎเรียกคืน**
2. กด **+ เพิ่มกฎ**
3. เลือก **Stage** และ **จำนวนวัน** ที่ไม่มีกิจกรรม
4. กด **Save**

**ตัวอย่าง**: Stage "โทรติดต่อ" ไม่มีกิจกรรม 3 วัน → คืนส่วนกลาง

---

## 5. จัดการทีม

1. ไปที่ menu **ทีม**
2. กด **+ สร้างทีม**
3. เพิ่มสมาชิกด้วยการพิมพ์ Email

**Role ในระบบ:**

| Role | สิทธิ์ |
|---|---|
| Admin | เห็นลีดทั้งหมด, ตั้งค่าทุกอย่าง |
| Team Lead | เห็นลีดของทีมตัวเอง, ตั้งค่า Rule/Stage |
| Staff | เห็นลีดของตัวเอง + ส่วนกลาง |

---

## 6. จัดการ Facebook Page

1. ไปที่ menu **เพจ**
2. กด **+ เพิ่มเพจ**
3. กรอก Page ID และ Page Access Token
4. กด **Save**

> Token ต้องเป็น Long-lived Token อายุไม่หมด หาได้จาก Facebook Developer Console

---

## 7. ประกาศ (Team Reminder)

ใช้ส่งข้อความแจ้งทีมทั้งหมด เช่น "วันนี้มีลีด VIP เข้ามา"

1. ไปที่ tab **Reminders**
2. กรอก **หัวข้อ** และ **รายละเอียด**
3. กด **ประกาศ**

ทุกคนในทีมจะเห็นประกาศนี้ในหน้า Reminders

---

## 8. ยอดสรุปประจำเดือน

แสดงใน tab **Reminders** ด้านบน แบ่งเป็น:

**ผลงานของฉัน:**
- Lead ทั้งหมด
- ส่งคูปอง
- จองแล้ว
- Recall เดือนนี้

**ทั้งทีม — แชทเดือนนี้:**
- แชทใหม่
- ตอบใน 5 นาที (%)
- เปลี่ยนเป็นลีด (%)

---

## 9. LINE Report อัตโนมัติ (ทุกวัน 16:00)

ระบบจะส่งสรุปผลงานรายวันเข้า LINE Group ทุกวัน 16:00 น. ประกอบด้วย:

- ลีดใหม่ / เลิกติดตาม / Recall
- แชทใหม่ / ตอบใน 5 นาที
- กิจกรรมรายคน (comment / ย้าย stage)
- แยก Bubble ตาม Pipeline

---

## 10. สีการ์ดลีดและความหมาย

| สี | ความหมาย | การดำเนินการ |
|---|---|---|
| ขาว | ปกติ | — |
| เหลือง | Pin ไว้ | ติดตามตามวัน Pin |
| แดงอ่อน | ใกล้ Recall | แจ้งทีมติดตามด่วน |
| ดำ | ไม่มีกิจกรรม >4 วัน | ตรวจสอบและมอบหมายใหม่ |

---

## 11. Checklist Admin รายสัปดาห์

- [ ] เช็คลีดสีดำ (ค้างเกิน 4 วัน) — มอบหมายใหม่หรือปิด
- [ ] เช็ค Recall ที่เกิดขึ้น — กระจายลีดส่วนกลางให้ทีม
- [ ] ดู LINE Report — เปรียบเทียบผลงานรายคน
- [ ] ตรวจสอบ Distribution Rule — token Facebook ยังใช้งานได้ไหม
- [ ] รีวิว Stage — มี Stage ที่ค้างลีดมากผิดปกติไหม
