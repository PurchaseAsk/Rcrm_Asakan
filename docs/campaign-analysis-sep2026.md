## 4. ลีด Unfollow ที่ Stage ไหน

**ข้อค้นพบสำคัญ: เกือบทั้งหมด unfollow หลังจากรับสายแล้ว — ไม่ใช่ก่อน**

| Stage ที่ Unfollow | ความหมาย |
|---|---|
| "ลีดใหม่" (น้อยมาก 1–2 ราย) | ไม่ได้รับการติดต่อเลย |
| **"โทรติดต่อ" และ "รับสายแล้ว" (ส่วนใหญ่)** | **รับสาย แต่คุยแล้วไม่สนใจต่อ** |

> **แปลว่า:** ปัญหาไม่ได้อยู่ที่คุณภาพลีดจาก ad — ลีดรับสาย
> **แต่ปัญหาอยู่ที่ script และสิ่งที่ Sales พูดในการโทรครั้งแรก**

## 5. Root Cause Analysis — ทำไม Unfollow สูง

```
❶ Ad ไม่มี Offer/Urgency ชัดเจน
   → คนกรอก form เพราะ "สนใจ" ไม่ใช่ "ตั้งใจซื้อ"
   → Lead เป็น warm curiosity ไม่ใช่ hot intent

❷ Sales ติดต่อช้า (เฉลี่ย 16–23 ชม.)
   → Lead เย็นลงมากแล้วก่อนได้รับการติดต่อ
   → ทำให้คนรู้สึกว่าโทรมาก็ได้ ไม่รีบ

❸ Sales ไม่นำเสนอ Promotion (ส่วนลด 100,000 บาท)
   → ทั้งใน caption และการพูดคุย
   → ลูกค้าไม่รู้สึก urgency ว่าต้องตัดสินใจตอนนี้

❹ ทีมชินกับโปรจนไม่รู้สึกว่าพิเศษ (Value Habituation)
   → Marketing ไม่ใส่ offer ใน artwork
   → Sales ไม่พูดถึงโปรในการโทร
   → ผลคือลูกค้าก็ไม่รู้สึก urgency เช่นกัน
```

## 6. ปัญหาโครงสร้าง Funnel (การตลาด)

ตอนนี้งบกระจุกที่ Bottom of Funnel เกือบทั้งหมด:

```
TOF — สร้างการรับรู้          4%   (รับรู้ MAR26)
MOF — Nurture / Retargeting   0%   ← ไม่มีเลย
BOF — Lead Form               96%
```

**ผลที่ตามมา:**
- ยิงหา cold audience แล้วขอให้กรอก form ทันที → คนที่ยังไม่พร้อมก็กรอกเพราะ curiosity
- คนที่ "สนใจแต่ยังไม่พร้อม" หายไปเลย ไม่มี retargeting รับ
- Frequency สูงบน audience เดิม เพราะไม่มีกลุ่มใหม่ป้อนเข้า funnel
